# Rust {#rust}

C/C++ と同じく、Rust はシステムプログラミング言語です。そのため、ファジング用のツール群は [C/C++ の節]({{% relref "/docs/fuzzing/c-cpp" %}})で説明したものと関係があります。Rust のファザーは、先に紹介したものをベースにしていることがあるためです。

ファジングの全般的な紹介とセットアップ（ハーネス、ファザーのランタイム、計装、SUT）については、[はじめに]({{% relref "fuzzing#introduction-to-fuzzers" %}})を参照してください。
