# C/C++ {#c-c}

このセクションでは、C/C++ プロジェクトをファジングする方法を、プロジェクトにファザーを組み込む手順も含めて説明します。C/C++ プロジェクトのファジングには多くの選択肢がありますが、このチュートリアルでは、libFuzzer と AFL++ の実践的な使い方を軸にします。この 2 つは、現在最もよく使われているファジングツールのうちの 2 つで、どんな C/C++ プロジェクトにも適用できます。

ファジングとファジングの設定（ハーネス、ファザーのランタイム、計装、SUT など）の全般的な紹介は、[はじめに]({{% relref "fuzzing#introduction-to-fuzzers" %}})を参照してください。 


## どのファザーをいつ使うべきですか？ {#when-should-i-use-which-fuzzer}

|||
|--- |--- |
|**libFuzzer**|シンプル。十分にテストされている。基本的なファジング機能を備える。マルチコアでのファジングは限定的。libFuzzer はメンテナンスのみのモードになっている|
|**AFL++**|十分にテストされている。業界標準。ほとんどのファジングの用途に足りる。マルチコアでのファジングに対応。最初のキャリブレーション段階があるため、短いファジングキャンペーン（CI でのファジングなど）には向かない|
|**LibAFL**|不安定な場合がある。複雑。ファジングの用途に合わせて調整できる。最先端のファジング技術に対応。Android、Windows など、より特殊なファジング環境にも対応|
{.skip-table-head}

ひとことで言えば、libFuzzer はファジングのテストをプロジェクトのコードベースに組み込むための設計で、開発者がファジングのテストを書いて保守しやすくなっています。AFL++ はセキュリティの専門家向けに作られており、セキュリティコンサルタントに好まれることが多いです。ファジングの経験がない場合は libFuzzer から始めることをお勧めします。より高機能な AFL++ への乗り換えは簡単だからです。
