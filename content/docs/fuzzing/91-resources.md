# 参考資料 {#additional-resources}

### 学習

- **[Awesome fuzzing list 1](https://github.com/cpuu/awesome-fuzzing)**: ファジングに関する学術論文を中心にまとめた、GitHub 上の一覧。
- **[Awesome fuzzing list 2](https://github.com/secfigo/Awesome-Fuzzing)**: ファザーとファジング関連の書籍についての、GitHub 上の一覧。
- **[Fuzzing handbook](https://www.fuzzingbook.org/)**: 学術的な観点で書かれたファジングのハンドブック。
- **[CNCF-Fuzzing handbook](https://github.com/cncf/tag-security/tree/main/community/resources/security-fuzzing-handbook)**: CNCF が作成したハンドブック。
- **[Fuzzing101](https://github.com/antonio-morales/Fuzzing101)**: GitHub Security Lab による、さまざまなファジング手法のチュートリアルと研修。
- **["How to Spot Good Fuzzing Research"](https://blog.trailofbits.com/2018/10/05/how-to-spot-good-fuzzing-research/)**: ToB のブログ記事
- **[39c3 "Demystifying Fuzzer Behaviour"](https://media.ccc.de/v/39c3-demystifying-fuzzer-behaviour)**: ファジングについての興味深い視点
- **[How to Build a Fuzzing Corpus](https://blog.isosceles.com/how-to-build-a-corpus-for-fuzzing/)**
