## 基礎理論

以下は、静的解析ツールに実装されている手法の概要です。

通常、ツールが対応しているのは次の解析の一部だけで、精度や網羅性もさまざまです。ツールにできることを知っておくことは、そのツールが役に立つかどうかを判断するうえで重要です。

### コードの見方

- 抽象構文木（AST）
- 制御フローグラフ（CFG）
- データフローグラフ（DFG）
- コールグラフ
- 中間表現（IR）
- 静的単一代入形式（SSA）
- Use-Definition チェーン（use-def）

### 解析

- AST の走査
- 抽象解釈
  - 定数伝播
  - 値の範囲の解析
- データフロー解析
- テイントトラッキング
- 制御フロー解析
  - 支配関係
  - 到達可能性
- ホーア論理
- モデル検査
- シンボリック実行
  - コンコリック実行
- 型解析
- エイリアス / ポインタ / points-to 解析
- プログラムスライシング
- グローバル値番号付け
- ハッシュコンシング

### 精度

- 手続き内
  - フロー感度（文の順序）
  - パス感度（条件分岐）

- 手続き間
  - コンテキスト感度（ポリバリアンス）
    - コールサイト
    - 型
    - オブジェクト
  - コンテキスト非感度

### 性質

- 健全性
- 精度
- 完全性
- 実行時間
