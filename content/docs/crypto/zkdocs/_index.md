# ゼロ知識プロトコル

ZKDocs は、ゼロ知識証明システムと関連するプリミティブについて、包括的で詳細な、対話的なドキュメントを提供します。

[Trail of Bits](https://www.trailofbits.com/) では、標準化されていない暗号プロトコルの実装を多数監査していて、同じ問題をたびたび見つけます。こうしたバグの事例が増えるにつれ、今後は防ぐ方法を見つけたいと考えるようになりました。しかし、こうしたプロトコルでは、低レベルの実装の細部やセキュリティ上の落とし穴をすべて把握する負担が、開発者にかかっています。

ZKDocs がこの隔たりを埋め、より広い暗号コミュニティの役に立つことを願っています。

**ゼロ知識証明システムの詳しい資料や対話型のガイドは、次を参照してください: https://zkdocs.com.**
{{< /hint >}}
