# 特定の HTTP リクエストを手動で扱う

対象のアプリケーションの仕組みを理解している場合(たとえば、セキュリティ上重要なリクエストを見分けられる場合)は、**Proxy** タブから適切なリクエストを選び、手動で攻撃を試せます。

たとえば、ユーザーが指定した値をレスポンスにそのまま反映するリクエストや、認証を扱う API 呼び出しは、この方法で調べる価値があります。半自動の手法で作業を支援するには、次の Burp のツールを使います。
