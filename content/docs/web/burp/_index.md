# Burp Suite Professional の紹介

## 1. Burp Suite Professional とは

Burp Suite Professional は、多数のセキュリティテスト機能を備えた HTTP 傍受プロキシです。クライアント（通常はブラウザで読み込んだ Web アプリケーション）とサーバーの間を流れる HTTP リクエストとレスポンスを、確認したり操作したりできます。

近ごろの Web サイトはトラフィックが増えていますが、Burp は並列のリクエストを扱える点で際立っています。対話的なツールを使えば、サイトがどう動くかについて仮説を立てて検証できます。大量のトラフィックを仕分ける必要がある場合でも同様で、これはほとんどのブラウザの開発ツールでは難しいことです。加えて Burp には高度な検索・フィルタ機能があり、大量のトラフィックを扱うときの作業効率を大きく高めます。リクエストの編集についても、Burp の UI はブラウザの開発ツールを大きく上回ります。

Burp には、大きく分けて 4 つの機能があります。

1. **Burp Proxy**。**Proxy** タブでは、プロキシを通ったリクエストとレスポンスを確認、並べ替え、絞り込みできます。
2. **Burp Scanner（アクティブとパッシブの両方）**。パッシブの Burp Scanner は、リクエストとレスポンスを分析し、起こりうる問題をユーザーに知らせます。アクティブの Burp Scanner は、サーバーに送るリクエストを生成して脆弱性の可能性を調べ、結果を表示します。
3. **Burp Repeater**。Burp Repeater では、リクエストを編集し、手軽に送信できます。
4. **Burp Intruder**。Burp Intruder では、リクエストの一部（クエリ文字列、POST パラメータ、URL パス、ヘッダーなど）を、あらかじめ用意したファジング用のペイロードの集合で埋め、ターゲットのサーバーへ自動的に送信できます。そのうえで、サーバーのレスポンスを表示するので、想定外の入力によるバグや脆弱性を見つける手がかりになります。

要するに Burp を使うと、HTTP トラフィックを取り込み、手軽に操作し、Burp に組み込まれたロジック（定義済みのルール）または手動の方法でセキュリティテストを行えます。

## 2. Burp はどこで役に立つか

Trail of Bits でのホワイトボックスのセキュリティ監査を通じて、私たちは、セキュリティ上の脆弱性を見つけるのが常に簡単とは限らないことを学びました。たとえば、次のような難しさがあります。

* 脆弱性の中には、多数のサードパーティライブラリや、その設定に起因するものがあります。
* 大規模な製品は、複雑なインフラストラクチャに散らばるさまざまなコンポーネントで構成されます。そのため、システムが現実にどう動くかを予測するのは困難です。
* バグがあるかどうかは、デプロイ環境の設定（たとえばステージングと本番）によって変わります。

Burp は、次のことに役立つ実用的なツール群を提供して、これらの難しさに対処します。

* サーバー側の問題や、想定外の挙動を見つける。
* クライアント側の脆弱性を見つける（Burp の DOM Invader Chromium 拡張機能の助けを借ります）。
* フロントエンドに送られるデータを読み解き、その目的とアプリケーションの挙動への影響を明らかにする。React や Webpack などのライブラリでコードが難読化されている場合も同様です。
* クライアントが提供すべきデータ（Cookie やヘッダーなど）を把握する。また、クライアント側にデータを保存する期間が、現地の規制に適合しているかを確認する。
* トラフィックの発信元の地域が違う場合や、ユーザーの設定が有効・無効の場合など、さまざまな状況で Web アプリケーションがどう動くかを知る。
* 組み込みの包括的なツールを使い、複数のクエリパラメータやヘッダーの値を、大がかりなスクリプトなしで同時に効率よくファジングする。たとえば Intruder ツールでは、リクエストのさまざまな部分をファジングできます。特定の入力の組み合わせがあるときにだけ現れる問題を、掘り起こせます。

アプリケーションがどれほど複雑で、どのような課題があっても、Burp Suite は包括的なツールキットを備えています。潜在的なセキュリティ脆弱性を見つける力を、大きく高められます。
