# C/C++ プログラムのセキュリティチェックリスト

C と C++ は、アプリケーション開発とシステムプログラミングで最もよく使われる言語の 2 つです。このセキュリティチェックリストは、セキュリティ監査担当者と安全な開発の実践者に向けて書かれており、C と C++ のコードをレビューするときに探すべきセキュリティ上の問題を幅広く挙げています。言語に固有のバグの種類に加えて、Linux と Windows の両方にまたがる、ユーザーモードのアプリケーションとカーネルモードのドライバを含む、環境に固有のセキュリティ問題も扱います。どんなチェックリストにも網羅性はありませんが、この文書が、C と C++ のコードで見つかりやすく影響も大きいセキュリティ問題を調べるための、確かな出発点になれば幸いです。

まず、私たちの [c-review](https://github.com/trailofbits/skills/tree/main/plugins/c-review) スキルでレビューを始めてください。基本的な問題を扱います。
